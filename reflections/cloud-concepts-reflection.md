In today's advancement of technology, one example here is a cloud service. Not everyone knows what it is, but they are actually using it in their daily lives. The cloud services I use are GCash, Messenger, and YouTube.
Gcash: This is a Software as a Service (SaaS) built on a Public Cloud. It lets people send money, pay bills, and manage a digital wallet straight from their phones. Users don't have to worry about how the tech works in the background—GCash handles all the servers and security so millions of people can use it every day. Messenger: This is a SaaS app running on Meta’s  Public Cloud. It gives us a simple way to text, call, and video chat with friends in real time. We just open the app and use it, while Meta takes care of all the complex servers and networking behind the scenes. YouTube: This is a SaaS platform that runs on Google’s massive Public Cloud. It lets anyone watch or upload videos instantly. Google handles all the heavy lifting—like storing billions of videos and streaming them smoothly—so users can just enjoy the content without needing extra software or technical setup.
Version control is very important when working with cloud projects. Today, cloud networks and servers are often set up using code. If we do not track changes to this code, it is easy to make mistakes that can break the system. Git and GitHub help teams work together without causing errors. Team members can create their own separate work areas to write and test new code without affecting the live project. Before adding new changes to the main system, other team members can check the code for errors.
